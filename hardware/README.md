# 硬件与接线

## 开发板

| 项目 | 说明 |
|---|---|
| 型号 | 杭州康芯 HX1P35A |
| FPGA | 安路 PH1P35MDG324（38184 LUT、42432 DFF、108 块 RAM、40 DSP） |
| 下载 | 板载 AL-LINK，Type-C |
| 显示 | HDMI 1.4 输出（1280×720@60），接 11.6 寸显示屏 |
| 摄像头 | 专用 MIPI FPC40 接口，附 40P 转 24P 软线 |

## 摄像头

| 项目 | 说明 |
|---|---|
| 型号 | Smartsens SC500CS |
| 像素 | 500 万，阵列 2600×1952 |
| 输出 | 10/8-bit 2-lane MIPI |
| 工程配置 | 1280×720、RAW10、BGGR、30 fps、VTS=2000 |

## 按键

| 丝印 | 管脚 | 工程信号 | 功能 |
|---|---|---|---|
| KEY0 | D5 | `I_key1` | 循环切换主模式：正常彩色 → 边缘 → 二值化 → 色彩识别 |
| KEY1 | A9 | `I_key2` | 子模式：正常彩色下切原图/油画；色彩识别下切分块/运动 |
| KEY2 | B9 | 未分配 | 预留 |
| KEY3 | C7 | 未分配 | 预留 |

按键消抖在 75 MHz 像素时钟下做 4 级同步 + 100000 周期计数释放，触发一次只产生一个脉冲；
模式值在 `vsync` 上升沿提交，因此切换发生在帧边界，不会撕裂画面。

## RGB LED

| 丝印 | 管脚 | 工程信号 | 说明 |
|---|---|---|---|
| J1-2 | V1 | `O_led_red` | 识别到红色目标时点亮 |
| J1-3 | U2 | `O_led_green` | 识别到绿色目标时点亮 |
| J1-4 | U1 | `O_led_blue` | 识别到蓝色目标时点亮 |
| J1-12 | — | GND | 外接 LED 模块地 |

引脚配置为 `LVCMOS33`、`DRIVESTRENGTH=4`、`PULLTYPE=PULLDOWN`，输出高电平点亮共阴 LED 模块。
只在“色彩识别”模式下更新；退出该模式或没有有效目标时三色全灭。

## 上电检查

1. HDMI 显示器能识别 1280×720@60；
2. 画面左上角有安路 Logo，左下角显示模式名；
3. 按 KEY0 能在四种主模式间切换，切换发生在帧边界，无撕裂；
4. 正常彩色下按 KEY1 能切到油画，色彩识别下按 KEY1 能切到运动检测；
5. 把红/绿/蓝物体放到画面中，对应 LED 点亮；
6. 弱光/强光下画面亮度稳定（AE 工作），白色物体不偏色（AWB 工作）。

## 常见接线问题

- **没有画面**：先确认 HDMI 线接在开发板 HDMI OUT，而不是 IN；再确认显示屏支持 720p60；
- **画面偏色/过暗**：确认摄像头 FPC 方向与 40P 转 24P 软线接触良好，再检查 AWB/AE 是否收敛；
- **MIPI 误码**：`S_lane_error` 会阻止坏帧发布，表现为画面停顿；检查软线长度与屏蔽；
- **LED 不亮**：确认 J1 排针的 LED 模块是共阴接法（J1-12 接 GND），且当前处于色彩识别模式。
