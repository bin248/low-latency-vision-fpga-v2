# 04 · 参数与调参

所有参数集中在例化处或模块参数表，改完重新综合即可。先看“症状 → 调哪个”，再看完整参数表。

## 1. 现场症状 → 参数

| 现象 | 优先调 | 方向 | 说明 |
|---|---|---|---|
| 暗光下蓝/绿不出框 | 蓝色 `y/sat` 门槛、绿色 `G_MIN` | 调小 | 暗光硬门槛，先降这一组 |
| 背景被误判成某色 | `MARGIN`/`gap` | 调大 | 要求目标分量比其它分量更高 |
| 框忽大忽小（呼吸） | `SMOOTH_DEAD` | 调大 | 8 → 12 更稳，但位置偏差变大 |
| 快速移动跟不上 | `SMOOTH_STEP` | 调大 | 24 → 32 更跟手，但更易跳 |
| 目标闪烁消失 | `HOLD_FRAMES` | 调大 | 3 帧 ≈ 0.1 s |
| 同色多目标只出一个框 | 候选槽数/绿色单目标 | — | 红/蓝各 2、绿 1 是资源折中 |
| 运动小目标漏检 | `DIFF`、`votes>=6`、最小框 16×6 | 调小/放宽 | 代价是噪声误触发 |
| 镜头晃动就报运动 | `flood` 阈值（1/4 帧） | 调大 | 大面积变化本就不算目标 |
| 计数不增加 | 中心判据、`armed` 4 帧 | — | 目标要真正穿过 (640,360) |
| 油画细节太少 | 桶数、量化位宽 | — | 4 桶/4 bit 是资源与效果的折中 |
| 快速运动有拖影 | `TNR_EN`、`DIFF_MAX` | 关小/调小 | TNR 对快速目标本来就不友好 |
| 画面过曝/泛白 | `TARGET_LUMA` | 调小 | 130 → 110 |
| 颜色偏冷/偏暖 | AWB 增益范围/死区 | — | 先确认光源 |

## 2. 调参顺序

**先调颜色 → 再看运动 → 最后调油画/降噪。**

1. 颜色：用一个纯色物体，调红/绿/蓝判决与 `MIN_AREA`，直到只有目标出框；
2. 运动：在颜色框正常后，再调 `DIFF`/票数/最小框，避免把颜色漏检当成运动问题；
3. 油画/TNR：最后调，二者都影响观感但不影响检测。

## 3. 模式与阈值

| 位置 | 参数 | 默认 | 作用 |
|---|---|---|---|
| `design_top_wrapper.v` | `S_edge_thresh` | 100 | 边缘阈值（固定常量） |
| `design_top_wrapper.v` | `S_bin_thresh` | 128 | 二值化阈值（固定常量） |
| `edge_detect.v` | `HYST_STAGES` | 3 | 滞后连接 7×7 |
| `edge_detect.v` | `EDGE_SHAPE_FIX` | 1 | 形态学修复开关 |
| `edge_detect.v` | `BIN_DIAG_EN` | 0 | 二值化调试面板 |
| `edge_detect.v` | `BIN_LOCAL_EN` | 0 | 局部阈值（默认关） |
| `edge_detect.v` | `BIN_MAJORITY_EN` | 0 | 多数表决（默认关） |

阈值改完要重新综合；如果想让按键调阈值，需要把 `S_edge_thresh/S_bin_thresh` 从常量改回
`thresh_ctrl` 的输出，并把 KEY2/KEY3 接进 `pin.adc`（本工程未接）。

## 4. 颜色分块参数

| 参数 | 默认 | 作用 |
|---|---|---|
| 红判决 | `R>G+40, R>B+40, R>60` | 红目标弱判决 |
| 绿判决 | `G≥R+20, G≥B+20, G≥36` | 绿目标弱判决 |
| 强绿 | `G≥R+24, G≥B+24, G≥44` | 强目标 |
| 蓝判决 | `y≥16, sat≥8, sat≥max/8, B>R/G+max(max/4,10)` | 蓝目标弱判决 |
| 强蓝 | `y≥20, sat≥16, sat≥max/4, B>R/G+max(max/4+max/8,12)` | 强目标 |
| 空间核心 | 3×3 至少 5 票 | 红/绿弱目标去孤点 |
| `MIN_AREA` | 200 | 目标最少像素数 |
| `MIN_W/MIN_H` | 8 / 8 | 最小框 |
| `MIN_STRONG` | 32 | 强像素最少数量 |
| `BORDER` | 12 | 最外圈不参与统计 |
| `SMOOTH_DEAD/STEP` | 8 / 24 | 框边死区与每帧限幅 |
| `HOLD_FRAMES` | 3 | 丢失保持帧数 |

颜色判决针对 **Gamma + AWB 之后**的 RGB；白平衡漂移明显时要重新确认。

## 5. 帧差运动参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `DIFF`（`motion_word_observer`） | 16 | 单通道绝对差阈值 |
| 票数 | ≥6/16 | 一个 128 bit 字算 hot |
| `streak` | ≥2 | 连续 hot 字数 |
| 行配对间距 | ≤8 px | 同一行左右段连接 |
| `hot_words` 范围 | 24 ~ FRAME_WORDS/4 | 排除零星噪声与大面积晃动 |
| 最小框 | 16 × 6 | `xmax-xmin≥15, ymax-ymin≥5` |
| 中心判据 | (640,360) | 目标框覆盖中心 |
| `armed` | 离开中心 4 帧 | 防止在中心抖动反复计数 |
| `HOLD_FRAMES`（告警） | 120 帧 | 目标消失后着色保持 |
| `TNR DIFF_MAX` | 8 | 相似通道融合门限 |

运动检测只看“相对上一帧同地址变化”，不估计运动方向，也不做光流；目标必须有纹理/边缘，
纯色大面积平移可能只在小范围触发。

## 6. 油画与 TNR

| 参数 | 默认 | 作用 |
|---|---|---|
| 邻域 | 5×5 | 油画窗口 |
| 量化位宽 | 4 bit/通道 | 颜色档位 |
| 桶数 | 4 | 按亮度 `lum[5:4]` 分桶 |
| 边界 | `BORDER+4` 圈 | 不处理，避免黑边 |
| `TNR_EN` | 1 | 时域融合总开关 |
| `BURST_WORDS` | 48 | 读页突发长度 |

## 7. 三个注意点

1. **颜色阈值依赖白平衡**：阈值针对 Gamma + AWB 之后的 RGB，白平衡漂移明显时要重新确认；
2. **暗部提亮会放大噪声**：Gamma 抬升暗部的同时抬升噪声，需要 RAW 域滤波配合；
3. **参数只在帧边界生效**：调完看到的变化最多晚一帧，属于正常现象。
