# 05 · 资源、验证与限制

## 1. 资源构成

| 资源类别 | 主要来源 | 说明 |
|---|---|---|
| 片内 RAM | 多级 3×3 窗口行缓冲；读/写异步 FIFO（128×512 bit）；中文与计数面板字模、Logo 位图 | 行缓冲随窗口级数线性增长 |
| DSP | AWB 的 R/B 像素乘法；饱和度增强；去马赛克插值 | 视觉统计、颜色判决、油画投票不占 DSP |
| 逻辑 LUT | Canny 变体、颜色分块、帧差、油画、OSD、按键控制 | 颜色分块每色增加比较/计数/匹配 |
| 片外 DDR | 4 页视频帧缓存，每页 172 800 个 128 bit 字 | 不占片内 RAM |
| 时钟 | PLL 输出 100/23.81/75/375 MHz；DDR 用户约 66 MHz | 跨域用异步 FIFO 与打包握手 |

> 仓库不附带比特流与综合报告。improve8 的功能密度很高，**具体 LUT/DFF/DSP 占用以你本地 TD 报告为准**；
> 如果 `gate.qor` 的 DSP 数超过 40，给乘法多的自写模块加 `(* dsp_style = "no" *)`，让乘法走 LUT。

## 2. 带宽

| 方向 | 速率 | 说明 |
|---|---|---|
| 写（摄像头 → DDR） | 约 82.9 MB/s | 30 fps × 2.76 MB；240 字突发 |
| 读（DDR → 显示，TNR 开） | 约 331.8 MB/s | 60 fps × 2.76 MB × 2 页（当前 + 参考）；48 字突发 |
| 读（DDR → 显示，TNR 关） | 约 165.9 MB/s | 只读当前页 |
| 合计（TNR 开） | 约 414.7 MB/s | 约占 66 MHz × 128 bit 的 39% |

带宽不是瓶颈；真正影响观感的是突发长度与 FIFO 深度：写攒 240 字、读 48 字，FIFO 512 字覆盖 DDR 返回延迟。
`TNR_EN=0` 时读带宽减半，可用来对比“融合/不融合”对画质与运动框的影响。

## 4. 已知限制

| 限制 | 说明 |
|---|---|
| 每种颜色最多 2 个框 | 红色/蓝色各 2 个候选，绿色只保留 1 个；同色多目标会合并或漏掉 |
| 形状只出框、不分类 | `color_detect` 的 `O_shape` 固定为 `12'hfff`，没有矩形/圆形/三角形判决 |
| 框滞后一帧 | 快速移动晚约 33 ms，大幅瞬移要几帧追上 |
| 死区带来位置偏差 | 稳定后框边最差差 8 像素，每帧最多移动 24 像素 |
| 运动检测是字级差分 | 16 字节块，最小目标约 30×10；纯色大面积平移、缓慢移动可能漏检 |
| 中心计数依赖覆盖中心 | 目标必须覆盖 (640,360)，且先离开中心 4 帧才重新 arm |
| 镜头晃动可能误报 | 大面积变化会置 `flood`，只有 `hot_words` 在 24~1/4 帧之间才算目标 |
| 油画细节被压平 | 4 bit/通道、4 个亮度桶；边界 `BORDER+4` 圈仍显示原图 |
| TNR 有轻微拖影 | 相似通道做平均，快速运动边缘会保留一点残影；可把 `TNR_EN` 置 0 |
| 只有 KEY0/KEY1 接入 | KEY2/KEY3 未分配管脚；阈值是常量，不能在板上调 |
| 外部执行器未接入 | 识别结果只做可视化与 LED 指示，没有 GPIO/UART 输出 |
| 加密 IP 不在仓库 | 需要自行获取 D-PHY/DDR/HDMI/PLL/FIFO/除法器/RAM/Logo ROM |

## 5. 复现步骤

1. 安装 TD 6.2 与器件库，新建工程（`PH1P35MDG324`、速度 `-3`）；
2. 加入 `rtl/` 全部 `.v`（先读 `rtl/vendor/README.md`，把 IP 放进 `vendor_ip/`）；
3. 加入 `constraints/pin.adc` 与 `constraints/camera_to_dsi_display.sdc`，按 `scripts/` 的模板跑综合/布局；
4. 生成比特流、烧录；
5. 上电确认 HDMI 有画面，KEY0 切换四种主模式，KEY1 切换油画/运动；
6. 跑 `tests/` 回归，确认改动没有破坏模式映射与行为模型。

## 6. 常见问题

**Q：TD 报一片 black box？**
先看是不是某个源文件里有非法数字字面量（如 `11'sd-10`），TD 前端解析失败会让后面所有文件变黑盒；
再确认新增文件是否在工程文件列表里，以及 vendor IP 是否都补齐。

**Q：布局报 “Can not place Macro”？**
先看 `gate.qor` 的 `#DSPs` 是否超过 40；超过时给乘法多的自写模块加 `(* dsp_style = "no" *)`，
让乘法走 LUT；也确认 `scripts/phy_settings.cfg` 里的 `pack_effort high` / `hfn_opt_effort low` 已生效。

**Q：烧录后画面没变？**
确认烧的是新生成的 `.bit`，不是 `best_result/` 里的旧文件；再确认工程路径指向本目录。

**Q：颜色识别不出框？**
先确认摄像头画面本身有颜色（AWB 正常），再降蓝色 `y/sat` 门槛或绿色 `G_MIN`，最后检查 `MIN_AREA`
是否过大、目标是否小于 8×8。

**Q：运动检测不计数？**
确认当前在“色彩识别 → 帧差运动”子模式；目标要覆盖画面中心 (640,360)，并且先完全离开中心 4 帧
再进入；画面大面积晃动会置 `flood`，不计为运动。

**Q：油画模式没变化？**
KEY1 只在主模式 0（正常彩色）下切换油画；画面四周 `BORDER+4` 圈仍显示原图，属于正常现象。

**Q：MIPI 误码导致画面停顿？**
`S_lane_error` 会阻止坏帧发布；检查 40P 转 24P 软线方向、长度与屏蔽，再确认摄像头供电稳定。
